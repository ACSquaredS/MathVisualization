# MathVisualization

Plotting and figures for [MathCraft](https://github.com/ACSquaredS/MathCraft), an open-source, MATLAB-inspired numerical computing environment.

> **Status:** Early stage. The repository is set up; implementation has not started.

## Role in MathCraft

MathVisualization turns MathCraft data into figures. Other modules call it to show their results.

## Depends on

- [MathCore](https://github.com/ACSquaredS/MathCore)

## Planned scope

- 2D plots: line, scatter, bar and histogram
- 3D plots: surface and mesh
- Figure, axes, legend and colorbar management
- Export to image formats (PNG, SVG)
- Interactive viewing (later stage)

## Boundaries

This module draws data. It does not compute it.
